# Taara — Jewelry Website

A premium, elegant, and responsive jewelry website designed to showcase timeless jewelry collections through a modern digital storefront.

## About the Project

Taara is a frontend jewelry website created to provide customers with a visually appealing and seamless browsing experience. The website features curated jewelry collections, product categories, and essential business information.

The project focuses on elegant design, responsive layouts, and a user-friendly interface suitable for a modern jewelry brand.

## Features

* Responsive design for desktop, tablet, and mobile devices.
* Elegant homepage with premium jewelry visuals.
* Dedicated pages for different jewelry collections.
* Jewelry categories including earrings, necklaces, and rings.
* About page showcasing the brand.
* Contact page for customer enquiries.
* Clean navigation and user-friendly layout.

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Responsive Web Design

## Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Vaibhavi-14shetty/Taara.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
